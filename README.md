### [📋 Gerenciador de Tarefas](https://github.com/rafaelvassis/GerenciadorTarefas) &nbsp;·&nbsp; [🔗 Ver online](https://gerenciador-tarefas-rafaelvassis-eabdewc9e3f5cved.brazilsouth-01.azurewebsites.net)

Aplicação **full stack** para organizar tarefas, com categorias, participantes e filtros, publicada na nuvem com deploy automatizado.

- CRUD completo com modelo relacional (1:N e N:N) e regras garantidas também no banco
- Arquitetura **MVC**, migrations automáticas e dados iniciais na primeira execução
- Deploy contínuo com **GitHub Actions** no **Azure App Service** e **Azure SQL**

### [🎮 Catálogo de Jogos](https://github.com/rafaelvassis/Catalogo-de-Jogos) &nbsp;·&nbsp; [🔗 Ver online](https://game-catalog-lovat.vercel.app)

Aplicação **full stack** para cadastrar, listar, editar e excluir jogos, com API REST em .NET e frontend React instalável como **PWA**.

- API em **ASP.NET Core (Minimal API)** com endpoints REST e CORS configurável, empacotada em **Docker**
- Frontend **mobile first** em **React 19 + Vite**, com validação por campo e tratamento de falhas da API
- Deploy do backend e do frontend na **Vercel**
